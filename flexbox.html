O que é o Flexbox?

O Flexbox (Flexible Box Layout) é um modelo de layout unidimensional: ele organiza os elementos em uma linha OU em uma coluna, distribuindo o espaço disponível e alinhando os itens com poucas linhas de CSS.

Tudo começa com dois papéis:

  • Flex container — o elemento pai, que recebe display: flex;;
  • Flex items — os filhos diretos do container, que passam a ser organizados por ele.
.container {
  display: flex;
}

Só os filhos diretos viram flex items. Netos não são afetados.

Eixo principal e eixo cruzado

O Flexbox trabalha com dois eixos. O eixo principal (main axis) é a direção em que os itens são colocados; o eixo cruzado (cross axis) é perpendicular a ele.

  • Com flex-direction: row (padrão): principal = horizontal, cruzado = vertical;
  • Com flex-direction: column: principal = vertical, cruzado = horizontal.

Por isso, justify-content alinha no eixo principal e align-items alinha no eixo cruzado.

Básico 4: gap e flex-wrap

gap cria espaço entre os itens sem precisar de margens. Por padrão, o Flexbox mantém tudo em uma linha só; com flex-wrap: wrap, os itens que não cabem passam para a linha de baixo.

Intermediário 1: flex-grow, flex-shrink e flex-basis

Controlam como cada item cresce, encolhe e qual é seu tamanho inicial.

  • flex-grow — quanto do espaço livre o item pode ocupar (padrão: 0);
  • flex-shrink — o quanto ele aceita encolher quando falta espaço (padrão: 1);
  • flex-basis — tamanho inicial no eixo principal, antes de crescer ou encolher (padrão: auto).

Intermediário 2: align-self e order

align-self sobrescreve o align-items de um único item. order muda a ordem visual sem mexer no HTML (padrão: 0; valores menores vêm primeiro).

align-self: item 1 no topo, item 2 centralizado, item 3 embaixo

1
2
3

order: o HTML é 1, 2, 3, mas a tela mostra 2, 3, 1

1
2
3
.item:nth-child(2) { align-self: center; }
.item:nth-child(1) { order: 3; }

Cuidado: order altera só o visual. Leitores de tela e a tecla Tab continuam seguindo a ordem do HTML.

Intermediário 3: align-content

Quando há várias linhas (com flex-wrap: wrap), o align-content distribui as linhas no eixo cruzado, como o justify-content faz com os itens. Com uma linha só, ele não tem efeito. 

.container {
  display: flex;
  flex-wrap: wrap;
  height: 300px;
  align-content: space-between;
}

Resumo da diferença entre as três propriedades de alinhamento:

  • justify-content — itens no eixo principal;
  • align-items — itens no eixo cruzado, dentro de cada linha;
  • align-content — as linhas inteiras no eixo cruzado.
