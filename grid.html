O que é o CSS Grid?

O CSS Grid é um modelo de layout bidimensional: ele organiza os elementos em linhas E colunas ao mesmo tempo, como uma grade ou tabela.

Vocabulário básico:

  • Grid container — o elemento pai, com display: grid;;
  • Grid items — os filhos diretos do container;
  • Track — uma linha ou uma coluna da grade;
  • Célula — o encontro de uma linha com uma coluna;
  • Grid lines — as linhas numeradas que separam as tracks (começam em 1);
  • Gap — o espaço entre as tracks.
.container {
  display: grid;
}

Só display: grid ainda não muda muito o visual: é preciso dizer quantas colunas e linhas queremos.

Funciona igual às colunas. Aqui, a primeira linha tem 40px e a segunda 90px.

3. Espaçamento: gap

gap define o espaço entre linhas e colunas. Também existem row-gap e column-gap para controlar cada um separadamente.

1
2
3
4
5
6
.container {
  gap: 10px;                 /* linhas e colunas */
  column-gap: 30px;          /* só colunas */
  row-gap: 10px;             /* só linhas */
}

4. Posicionando itens: grid-column e grid-row

Um item pode ocupar várias células. Usamos os números das grid lines ou a palavra span.

a: 1 / 3
b: span 2
c: row span 2
5
6
d: 1 / -1 (linha inteira)
.a { grid-column: 1 / 3; }     /* começa na linha 1, termina na 3 */
.b { grid-column: span 2; }    /* ocupa 2 colunas */
.c { grid-row: span 2; }       /* ocupa 2 linhas */
.d { grid-column: 1 / -1; }    /* -1 = última linha da grade */

5. Grid responsivo: auto-fit e minmax

Com repeat(auto-fit, minmax(120px, 1fr)), o navegador cria quantas colunas couberem, cada uma com no mínimo 120px. Redimensione a janela para ver. É a mesma técnica usada na página inicial (hub) deste site.

1
2
3
4
5
6
.container {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(120px, 1fr));
  gap: 10px;
}
  • minmax(min, max) — define um tamanho mínimo e um máximo para a coluna;
  • auto-fit — encaixa o máximo de colunas e estica as restantes para ocupar a sobra;
  • auto-fill — parecido, mas mantém as colunas vazias reservadas.

6. Layout de página com grid-template-areas

Dá para "desenhar" o layout com nomes. Cada string é uma linha, e cada palavra é uma coluna. Repetir o nome faz o item ocupar várias células.

Topo
Menu
Principal
Rodapé
.container {
  display: grid;
  grid-template-columns: 150px 1fr;
  grid-template-rows: 50px 130px 50px;
  grid-template-areas:
    "topo   topo"
    "menu   principal"
    "rodape rodape";
}
.topo      { grid-area: topo; }
.menu      { grid-area: menu; }
.principal { grid-area: principal; }
.rodape    { grid-area: rodape; }

Para mudar o layout no celular, basta redefinir o grid-template-areas dentro de uma media query.

7. Alinhamento no Grid

O alinhamento usa nomes parecidos com os do Flexbox, mas aqui eles funcionam dentro de cada célula:

  • justify-items — alinha os itens na horizontal dentro da célula;
  • align-items — alinha os itens na vertical dentro da célula;
  • place-items — atalho para os dois (align-items justify-items);
  • justify-content / align-content — alinham a grade inteira dentro do container.

Um item específico pode ignorar a regra do pai com justify-self, align-self ou place-self.

Flexbox ou Grid?

FlexboxGrid
DimensõesUma (linha ou coluna)Duas (linhas e colunas)
Quem mandaO conteúdoO layout
Bom paraMenus, botões, barras, alinhamento de itensPáginas, galerias, painéis, formulários

Os dois funcionam juntos: use Grid para a estrutura da página e Flexbox para alinhar o conteúdo dentro de cada área. Neste site, o hub usa Grid e os cards usam Flexbox.

Atividade Prática

Crie uma página que contenha:

  • Uma galeria com 6 itens em 3 colunas iguais e gap;
  • Uma galeria responsiva com repeat(auto-fit, minmax(150px, 1fr));
  • Um layout de página (topo, menu, conteúdo, rodapé) com grid-template-areas;
  • Um item que ocupe a linha inteira usando grid-column: 1 / -1.
